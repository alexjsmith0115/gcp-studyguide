# Product name changes

Google renamed several products and features that a developer uses. Older exam questions, courses, and blog posts use the previous names, so learn both. The notes use the current docs name and put the previous name in parentheses at the first mention.

The PCD exam guide sometimes uses a name that differs from the docs. The second table maps these names. The third table lists products and features that Google retired or restricted, or that the docs no longer recommend.

Checked on 2026-09-30.
