## Why it matters

Gemini models on Gemini Enterprise Agent Platform, or Agent Platform (formerly Vertex AI), let an application generate text, code, and structured data through an API. A developer chooses the authentication, the endpoint, the output format, and the tools that the model can use. The developer also controls cost and quota use and handles `429` errors. The exam tests these choices with the Google Gen AI SDK.

## Key points

- The Google Gen AI SDK (`google-genai`) is one interface for the Gemini Developer API and the Gemini API on Agent Platform. With a few exceptions, code for one runs on the other ([Google Gen AI SDK](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/sdks/overview)).
- Google recommends an API key for testing and Application Default Credentials (ADC) for production ([Configure application default credentials](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/start/gcp-auth)).
- A principal needs `aiplatform.endpoints.predict` to send prompts. The Gemini Enterprise Agent Platform User role (`roles/aiplatform.user`) gives access to the generative AI features ([Access control](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/access-control)).
- The global endpoint gives higher availability and fewer `429` errors, but you cannot control where it processes a request ([Deployments and endpoints](https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/locations)). The endpoint decides where ML processing happens. A multi-region endpoint keeps it in a jurisdiction, such as the United States or the European Union. A regional endpoint, such as `us-central1`, keeps it in the jurisdiction of that region ([Data residency](https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/data-residency)).
- To get valid JSON every time, set both `response_schema` and `response_mime_type: "application/json"`. JSON mode without a schema is only a strong hint ([Structured output](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/control-generated-output)).
- In function calling, the model returns the function name and the arguments. Your application runs the function and sends the result back to the model ([Introduction to function calling](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tools/function-calling)).
- You cannot combine search tools, such as Grounding with Google Search, with function calling in the same request ([Grounding with Google Search](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/grounding/grounding-with-google-search)).
- When a filter blocks a response, the candidate content is empty and `finish_reason` gives the reason. For `gemini-3.5-flash` and later models, the default threshold is `OFF` ([Safety and content filters](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/configure-safety-filters)).
- Implicit caching is on by default. Explicit caching stores content that you reference by name, with a default lifetime of 60 minutes ([Context caching overview](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/context-cache/context-cache-overview), [Create a context cache](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/context-cache/context-cache-create)).
- Batch inference costs 50% less than real-time inference and is not for real-time use. One job can hold up to 200,000 requests ([Batch inference with Gemini](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/batch-inference)).
- On Standard pay-as-you-go, a `429` error means temporary contention for shared capacity, not a fixed quota. Retry with exponential backoff ([Standard PayGo](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/standard-paygo)).
- Model IDs retire. The docs list the retirement dates and the replacement models ([Model versions and lifecycle](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/model-versions)).

## Set up: API, IAM, SDK, and credentials

1. Enable the Agent Platform API (`aiplatform.googleapis.com`) in the project.
2. Grant `roles/aiplatform.user`, or a custom role with `aiplatform.endpoints.predict`, to the user or service account.
3. Install the SDK with `pip install --upgrade google-genai`.
4. For local development, run `gcloud auth application-default login`.
5. Create a client with the project and the location.

Sources: [Configure application default credentials](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/start/gcp-auth), [Access control](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/access-control), [Google Gen AI SDK](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/sdks/overview).

```python
from google import genai

client = genai.Client(enterprise=True, project="PROJECT_ID", location="global")
response = client.models.generate_content(
    model="gemini-3.5-flash",
    contents="How does AI work?",
)
print(response.text)
```

Sources: [Deployments and endpoints](https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/locations), [Text generation](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/send-chat-prompts-gemini).

`enterprise=True` selects the Gemini API on Agent Platform. Older samples use `vertexai=True`, which the SDK reference calls the legacy flag for `enterprise` ([Google Gen AI SDK reference](https://googleapis.github.io/python-genai/genai.html)).

| Credential | Use it for | What to know |
|---|---|---|
| ADC with a user account or a service account | Production, and local development | Google recommends it. IAM roles control access |
| API key from express mode (Preview) | Testing and fast starts | Express mode is for `@gmail.com` accounts. Hard-code a key only for a short test, because it is not secure |
| Firebase AI Logic client SDKs | Mobile and web apps that call Gemini directly | SDKs for Swift, Android, Web, Flutter, and Unity |

Sources: [Get started with Gemini Enterprise Agent Platform](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/start), [Get a Google Cloud API key](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/start/api-keys), [Gemini Enterprise Agent Platform in express mode overview](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/start/express-mode/overview), [Text generation](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/send-chat-prompts-gemini).

From August 27, 2026, Google temporarily restricts new access to the Gemini API from service accounts. Existing service accounts keep working. For new integrations with the Gemini API, Google recommends authentication-enabled API keys ([Service accounts overview](https://docs.cloud.google.com/iam/docs/service-account-overview)). The Manage API keys page uses the name Gemini API for `generativelanguage.googleapis.com`. It lists AI Platform (`aiplatform.googleapis.com`) as a separate API ([Manage API keys](https://docs.cloud.google.com/docs/authentication/api-keys)). For Gemini on Agent Platform, the authentication page still recommends ADC for production ([Configure application default credentials](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/start/gcp-auth)).

[Authenticating code to Google Cloud](note:1.2-authenticating-to-google-cloud) explains ADC on each platform.

## Choose an endpoint

The location in the client selects the endpoint. The choice is a trade-off between availability and control of the processing location.

| Endpoint | Host | Use it when | Do not use it when |
|---|---|---|---|
| Global | `aiplatform.googleapis.com` with `locations/global` | You want the best availability and fewer `429` errors | You have ML processing location requirements, or you need tuning |
| Regional | `LOCATION-aiplatform.googleapis.com` | You need one specific region | You want requests to move away from a busy region |
| Multi-region (`us` or `eu`) | `aiplatform.us.rep.googleapis.com` or the `eu` host | ML processing must stay in the United States or the European Union | You connect with Private Google Access. Use Private Service Connect instead |

Sources: [Deployments and endpoints](https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/locations), [Retry strategy](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/retry-strategy).

## Shape the request

System instructions and generation parameters control how the model answers. A system instruction applies to the whole request, across all turns. It can set a role, an output format, a tone, rules, and context. It does not fully prevent jailbreaks or leaks, so do not put sensitive information in it ([Use system instructions](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/prompts/system-instructions)).

| Parameter | What it controls | Guidance from the docs |
|---|---|---|
| `temperature` | Randomness of token selection. At `0`, responses are mostly deterministic | `1.0` is the recommended starting value. Use `0` or a low value for function calling. Use `1.0` for Grounding with Google Search |
| `max_output_tokens` | Maximum response length | A token is about four characters |
| `stop_sequences` | Strings that stop generation | Up to five |
| `system_instruction` | Persona, format, and rules for the whole request | No sensitive data |

Sources: [Text generation](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/send-chat-prompts-gemini), [Introduction to function calling](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tools/function-calling), [Grounding with Google Search](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/grounding/grounding-with-google-search), [Use system instructions](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/prompts/system-instructions).

### Streaming and multi-turn chat

`generateContent` returns the response after the model generates all of it. `streamGenerateContent` returns each part as soon as the model generates it, which reduces the latency that a person sees ([Text generation](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/send-chat-prompts-gemini)).

```python
chat_session = client.chats.create(model="gemini-3.5-flash")
for chunk in chat_session.send_message_stream("Why is the sky blue?"):
    print(chunk.text, end="")
```

Source: [Text generation](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/send-chat-prompts-gemini).

In a multi-turn chat, the SDK stores the earlier content locally and sends all of it with each new message. So the input cost of each message includes the whole conversation. If the first content is large, consider context caching ([Text generation](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/send-chat-prompts-gemini)).

## Structured output

A response schema makes the model return data that your code can parse without extra processing.

```python
response_schema = {
    "type": "ARRAY",
    "items": {
        "type": "OBJECT",
        "properties": {
            "recipe_name": {"type": "STRING"},
            "ingredients": {"type": "ARRAY", "items": {"type": "STRING"}},
        },
        "required": ["recipe_name", "ingredients"],
    },
}
response = client.models.generate_content(
    model="gemini-3.5-flash",
    contents="List a few popular cookie recipes.",
    config={
        "response_mime_type": "application/json",
        "response_schema": response_schema,
    },
)
print(response.text)
```

Source: [Structured output](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/control-generated-output).

Rules for response schemas ([Structured output](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/control-generated-output)):

- Fields are optional by default. List the fields that you always need in `required`.
- The schema counts toward the input token limit. A complex schema can cause an `InvalidArgument: 400` error.
- Do not repeat the schema in the prompt, because output quality can drop.
- Use `text/x.enum` to get one value from a fixed list, for example a classification label.
- You define a schema only through the API. The console does not support it.

## Function calling

Function calling (tool use) connects the model to your systems. The model does not run your function. It returns structured data that names the function and the arguments ([Introduction to function calling](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tools/function-calling)).

1. Declare each function with a name, a description, and parameters in an OpenAPI-compatible schema.
2. Send the prompt with the function declarations.
3. The model returns one function call, or several parallel calls.
4. Your application runs each function.
5. Your application sends all the results back, and the model writes the final answer.

Source: [Introduction to function calling](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tools/function-calling).

With the Gen AI SDK for Python, the docs sample passes a Python function in `tools`:

```python
from google.genai.types import GenerateContentConfig

def get_current_weather(location: str) -> str:
    """Returns the current weather.
    Args:
      location: The city and state, e.g. San Francisco, CA
    """
    return "sunny"

response = client.models.generate_content(
    model="gemini-3.5-flash",
    contents="What is the weather in boston?",
    config=GenerateContentConfig(tools=[get_current_weather]),
)
```

Source: [Introduction to function calling](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tools/function-calling).

| Mode | Behavior |
|---|---|
| `AUTO` (default) | The model chooses a function call or a text answer |
| `ANY` | The model always returns a function call. `allowed_function_names` limits the choice |
| `VALIDATED` | A function call or text, with schema adherence |
| `NONE` | No function calls, as if you sent no declarations |

Source: [Introduction to function calling](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tools/function-calling).

The best practices for function calling are ([Introduction to function calling](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tools/function-calling)):

- Write clear, specific function and parameter descriptions. Use `enum` for fixed values and strong types.
- Keep the active set to a maximum of 10 to 20 relevant tools. Too many tools increase the risk of a wrong choice.
- Put the current date, time, or location in the system instruction when functions need them.
- Use a temperature of `0` or another low value.
- Ask the user to confirm a call with significant results, such as an order or a database update, before you run it.

## Grounding

Grounding connects model output to sources that you can check. It reduces hallucinations and gives links to the sources ([Grounding overview](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/grounding/overview)).

| Grounding source | Use it when |
|---|---|
| Google Search | Answers need world knowledge or current public information |
| Agent Search (formerly Vertex AI Search) | Answers must come from your website data or your documents |
| RAG Engine on Agent Platform | You want a managed, configurable retrieval-augmented generation (RAG) service for your data |
| Elasticsearch, or your own search API | Your data is already in those search systems |

Sources: [Grounding overview](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/grounding/overview), [Gemini Enterprise Agent Platform name changes](https://docs.cloud.google.com/gemini-enterprise-agent-platform/vertex-ai-name-changes).

```python
from google.genai.types import GenerateContentConfig, GoogleSearch, Tool

response = client.models.generate_content(
    model="gemini-3.5-flash",
    contents="When is the next total solar eclipse in the United States?",
    config=GenerateContentConfig(tools=[Tool(google_search=GoogleSearch())]),
)
```

Source: [Grounding with Google Search](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/grounding/grounding-with-google-search).

Grounding with Google Search requires that you enable Google Search Suggestions, and it has a limit of one million queries each day. A request can combine several search tools, but not a search tool with function calling or the RAG Engine `retrieval` tool ([Grounding with Google Search](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/grounding/grounding-with-google-search)).

## Safety filters

Filters block harmful prompts and responses. They do not change how the model behaves. To steer the model, use system instructions ([Safety and content filters](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/configure-safety-filters)).

| Filter or setting | What to know |
|---|---|
| Non-configurable filters | Always block child sexual abuse material (CSAM) and personally identifiable information (PII) |
| Content filters | Harm categories: hate speech, harassment, sexually explicit, and dangerous content |
| Thresholds | `BLOCK_LOW_AND_ABOVE`, `BLOCK_MEDIUM_AND_ABOVE`, `BLOCK_ONLY_HIGH`, `BLOCK_NONE` (returns scores, no blocking), and `OFF` (no blocking, no scores) |
| Default threshold | `OFF` for `gemini-3.5-flash` and later models |
| Harm block method | `SEVERITY` (default) uses probability and severity scores. `PROBABILITY` uses only probability |
| Blocked prompt | `promptFeedback.blockReason`, for example `PROHIBITED_CONTENT` |
| Blocked response | Empty candidate content, and `finish_reason` such as `SAFETY`, `RECITATION`, or `SPII` |

Source: [Safety and content filters](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/configure-safety-filters).

Check the finish reason before you use the text. In the docs sample, `response.text` is `None` when a filter blocks the response:

```python
from google.genai.types import (
    GenerateContentConfig, HarmBlockThreshold, HarmCategory, SafetySetting,
)

response = client.models.generate_content(
    model="gemini-3.5-flash",
    contents=prompt,
    config=GenerateContentConfig(
        system_instruction=system_instruction,
        safety_settings=[
            SafetySetting(
                category=HarmCategory.HARM_CATEGORY_DANGEROUS_CONTENT,
                threshold=HarmBlockThreshold.BLOCK_LOW_AND_ABOVE,
            ),
        ],
    ),
)
print(response.text)                         # None if blocked
print(response.candidates[0].finish_reason)  # FinishReason.SAFETY if blocked
```

Source: [Safety and content filters](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/configure-safety-filters).

## Tokens, caching, batch inference, and embeddings

### Count tokens

`client.models.count_tokens(model=..., contents=...)` returns the token count of a prompt, and the API has no charge. For images, video, and audio, the count is an estimate. The exact billed usage is in `usage_metadata` of the response ([Use the Count Tokens API](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/get-token-count)). The SDK can also list and count tokens locally (Preview) ([List and count tokens](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/list-token)).

### Context caching

Context caching reduces the cost and latency of requests that repeat the same large content.

| Item | Implicit caching | Explicit caching |
|---|---|---|
| How it starts | On by default in all projects | You create a cache with the API |
| Discount | 90% on cached tokens | 90% on cached input tokens for Gemini 2.5 and later models |
| Storage cost | None | Charged for the time the cache is stored |
| Lifetime | — | 60 minutes by default. You can set `ttl` or `expire_time`, with no maximum |
| To get more cache hits | Put large, common content at the start of the prompt. Send requests with the same prefix close in time | Reference the cache name in `cached_content` |

Sources: [Context caching overview](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/context-cache/context-cache-overview), [Create a context cache](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/context-cache/context-cache-create).

```python
from google.genai.types import CreateCachedContentConfig, GenerateContentConfig

content_cache = client.caches.create(
    model="gemini-3.5-flash",
    config=CreateCachedContentConfig(
        contents=contents,                      # for example, PDFs in Cloud Storage
        system_instruction=system_instruction,
        display_name="example-cache",
        ttl="86400s",
    ),
)
response = client.models.generate_content(
    model="gemini-3.5-flash",
    contents="Summarize the pdfs",
    config=GenerateContentConfig(cached_content=content_cache.name),
)
```

Sources: [Create a context cache](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/context-cache/context-cache-create), [Use a context cache](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/context-cache/context-cache-use).

Put the system instructions and tools in the cache. A request that uses a cache cannot set them again. Content larger than 10 MB must come from a Cloud Storage URI, and you must not change those objects while the cache exists ([Use a context cache](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/context-cache/context-cache-use), [Create a context cache](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/context-cache/context-cache-create), [Context caching overview](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/context-cache/context-cache-overview)).

### Batch inference

Batch inference (formerly batch prediction) processes many prompts asynchronously from a JSON Lines (JSONL) file in Cloud Storage or from a BigQuery table.

| Item | Online inference | Batch inference |
|---|---|---|
| Response time | Real time | Most jobs finish within 24 hours after they start. A job can wait in the queue for up to 72 hours |
| Price | Standard | 50% discount. The 90% cache discount takes precedence, and the two do not stack |
| Size | One request | Up to 200,000 requests, and a Cloud Storage input file of up to 1 GB |
| Retries | Your code retries, or the SDK with `retry_options` | The service retries individual requests. Submit the job once |
| Not supported | — | Provisioned Throughput, explicit caching, and RAG |

Sources: [Batch inference with Gemini](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/batch-inference), [Retry strategy](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/retry-strategy).

```python
from google.genai.types import CreateBatchJobConfig

job = client.batches.create(
    model="gemini-3.5-flash",
    src="gs://BUCKET/prompts.jsonl",
    config=CreateBatchJobConfig(dest=output_uri),
)
print(job.state)  # JOB_STATE_PENDING
```

Source: [Batch inference from Cloud Storage](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/batch-inference/new-job-from-cloud-storage).

The AI Platform Service Agent must have permission to read the input file. Batch inference is not covered by an SLA ([Batch inference from Cloud Storage](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/batch-inference/new-job-from-cloud-storage), [Batch inference with Gemini](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/batch-inference)).

### Embeddings

An embedding is a vector that represents the meaning of text. Use embeddings to find passages with a similar meaning, even when the words differ ([Get text embeddings](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/embeddings/get-text-embeddings)).

```python
from google.genai.types import EmbedContentConfig

response = client.models.embed_content(
    model="gemini-embedding-001",
    contents=["How do I get a driver's license/learner's permit?"],
    config=EmbedContentConfig(
        task_type="RETRIEVAL_DOCUMENT",
        output_dimensionality=768,
    ),
)
```

Source: [Get text embeddings](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/embeddings/get-text-embeddings).

`gemini-embedding-001` returns 3,072 dimensions by default. A smaller `output_dimensionality` saves storage with a small loss of quality. One request takes up to 250 texts and 20,000 tokens. The API silently truncates each text after 2,048 tokens, unless you set `autoTruncate` to `false` ([Get text embeddings](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/embeddings/get-text-embeddings)).

## Quotas, 429 errors, and retries

A `429` error means that your requests exceed the capacity available to them. The correct fix depends on how you buy capacity.

| Consumption option | What it is | When you get `429` |
|---|---|---|
| Standard PayGo | Shared capacity. A usage tier, set by your organization's spend over 30 days, gives a baseline throughput for each model | Retry with exponential backoff. Use the global endpoint. Spread the traffic evenly, without sharp spikes |
| Priority PayGo | For latency-sensitive, high-reliability workloads, with no upfront commitment | Retry with exponential backoff, and check that you are within quota |
| Flex PayGo | Lower priority and slower processing | Do not retry aggressively. Increase the request timeout, for example to 30 minutes |
| Provisioned Throughput | A fixed-cost, fixed-term subscription that reserves throughput for a model | Usually you exceed the purchased capacity, so retries may not help. Buy more throughput. By default, extra requests run as pay-as-you-go |

Sources: [Standard PayGo](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/standard-paygo), [Retry strategy](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/retry-strategy), [Provisioned Throughput overview](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/provisioned-throughput), [Error code 429](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/deploy/error-code-429).

The Retry strategy page says that the Gen AI SDK retries transient errors (`429`, `5xx`, timeouts, and network errors) with exponential backoff by default ([Retry strategy](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/retry-strategy)). But in the Python SDK reference, the default value of `retry_options` is `None`. `attempts` counts the first request, and its default is 5 ([Google Gen AI SDK reference](https://googleapis.github.io/python-genai/genai.html)). Set `HttpRetryOptions` in your code, so that the retry behavior does not depend on the SDK version:

```python
from google import genai
from google.genai import types

client = genai.Client(
    enterprise=True,
    project=PROJECT_ID,
    location="global",
    http_options=types.HttpOptions(
        retry_options=types.HttpRetryOptions(
            initial_delay=1.0,
            attempts=3,  # the first request and at most two retries
            http_status_codes=[408, 429, 500, 502, 503, 504],
        ),
        timeout=120 * 1000,
    ),
)
```

Sources: [Retry strategy](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/retry-strategy), [API errors](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/models/api-errors), [Google Gen AI SDK reference](https://googleapis.github.io/python-genai/genai.html).

Retry rules from the docs ([Retry strategy](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/retry-strategy)):

- Retry `408`, `429`, and `5xx` errors. Do not retry `400` or `401` errors without a change to the request.
- Retry no more than two times, with a minimum delay of one second ([API errors](https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/models/api-errors)).
- `generateContent` is safe to retry because it does not change server state. Do not repeat requests that create resources, such as a tuned model.
- Add jitter, set a maximum number of attempts, and log each retry.
- For real-time chat, fail fast with few attempts.

A failed attempt has no charge. Google charges only for requests that return a `200` response code ([Agent Platform pricing](https://cloud.google.com/gemini-enterprise-agent-platform/generative-ai/pricing)).

[Efficient and resilient API calls](note:4.2-efficient-api-calls) covers backoff for other Google Cloud APIs.

Model IDs also change. For example, `gemini-2.5-flash` retires on October 20, 2026, and the docs name its replacement models. A retirement date can move later, but not earlier ([Model versions and lifecycle](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/model-versions)).

| Amazon Bedrock runtime APIs | Gemini API on Agent Platform with the Google Gen AI SDK | The same SDK also calls the Gemini Developer API |
| Amazon Bedrock Guardrails | Safety and content filters, and system instructions | Filters do not steer the model, and the default threshold is `OFF` for `gemini-3.5-flash` and later |
| Amazon Bedrock Knowledge Bases | Grounding with Agent Search or RAG Engine | Google Search grounding cannot share a request with function calling |
| Amazon Bedrock batch inference | Agent Platform batch inference | 50% discount and up to 200,000 requests in one job |
| Amazon Bedrock Provisioned Throughput | Provisioned Throughput | Requests over the purchase run as pay-as-you-go by default |
| Amazon Bedrock prompt caching | Context caching | Implicit caching is on by default |

## Exam traps

- **An API key in a production service.** Use ADC with a service account ([Configure application default credentials](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/start/gcp-auth)).
- **`response_mime_type: application/json` alone.** It is only a strong hint. Add `response_schema` ([Structured output](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/control-generated-output)).
- **Google Search grounding and function calling in one request.** The API does not support this combination ([Grounding with Google Search](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/grounding/grounding-with-google-search)).
- **The global endpoint for a data residency requirement.** You cannot control where it processes requests ([Deployments and endpoints](https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/locations)). Use a multi-region or regional endpoint. Each keeps ML processing in its jurisdiction ([Data residency](https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/data-residency)).
- **"The model ran my function."** Your application runs it and returns the result ([Introduction to function calling](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tools/function-calling)).
- **Retrying a `400` error, or retrying with no delay.** Fix the request. Use exponential backoff for transient errors only ([Retry strategy](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/retry-strategy)).
- **A quota increase as the first fix for Standard PayGo `429` errors.** The error shows temporary contention. Use backoff, the global endpoint, and smooth traffic ([Standard PayGo](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/standard-paygo)).
- **More retries for Provisioned Throughput `429` errors.** These errors usually mean that you used all the purchased capacity ([Retry strategy](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/retry-strategy)).
- **Using `response.text` without checking `finish_reason`.** A blocked response has no content ([Safety and content filters](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/configure-safety-filters)).
- **Batch inference for a chat feature.** Batch jobs are asynchronous. A job can wait in the queue for up to 72 hours, and then it can run for up to 24 hours ([Batch inference with Gemini](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/batch-inference)).
- **System instructions in a request that uses a cache.** Put them in the cache ([Use a context cache](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/context-cache/context-cache-use)).
