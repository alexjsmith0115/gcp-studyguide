## Why it matters

The architect decides when a pre-trained API is enough and when a Gemini prompt, a prebuilt product, or a Model Garden model fits better. The exam names six AI API families: Search, Conversation, Vision, Image, Video, and Audio. Many of these products changed names in 2025 and 2026, and some are deprecated. Questions also test Gemini Enterprise agents, Gemini Notebook Enterprise (formerly NotebookLM Enterprise), and the setup of Model Garden models.

## Key points

- Agent Search (formerly Vertex AI Search) builds search and recommendation apps over your data. It uses the Discovery Engine API ([Agent Search documentation](https://docs.cloud.google.com/generative-ai-app-builder/docs)).
- CX Agent Studio is the evolution of Dialogflow CX. The docs call Dialogflow CX and Dialogflow ES "legacy" ([CX Agent Studio](https://docs.cloud.google.com/gemini-enterprise-cx/cx-agent-studio)).
- Use the Vision API to analyze images. Use Document AI for document processing pipelines and scanned documents ([OCR with Google AI](https://cloud.google.com/use-cases/ocr), [Vision features list](https://docs.cloud.google.com/vision/docs/features-list)).
- The Imagen image generation endpoints are deprecated. Google recommends Gemini image models as the replacement ([Release notes](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/release-notes)).
- The Video Intelligence API is deprecated from September 14, 2026 and shuts down on September 14, 2027. Google recommends Gemini models ([Video Intelligence API documentation](https://docs.cloud.google.com/video-intelligence/docs)).
- Chirp 3 transcription works only in the Speech-to-Text V2 API ([Chirp 3 Transcription](https://docs.cloud.google.com/speech-to-text/docs/models/chirp-3)).
- Cloud Translation - Advanced adds glossaries and regional endpoints, but it does not accept API keys ([Overview of the Cloud Translation API](https://docs.cloud.google.com/translate/docs/api-overview)).
- Gemini Enterprise is an intranet search, AI assistant, and agentic platform. Its search results follow each user's permissions ([What is Gemini Enterprise?](https://docs.cloud.google.com/gemini/enterprise/docs)).
- Google Agentspace became Gemini Enterprise in October 2025. Agent Designer became Workflow Builder, which is GA ([Gemini Enterprise release notes](https://docs.cloud.google.com/gemini/enterprise/docs/release-notes)).
- NotebookLM Enterprise is now Gemini Notebook Enterprise. Gemini Enterprise Standard and Plus include it, and Google also sells it alone ([Gemini Enterprise release notes](https://docs.cloud.google.com/gemini/enterprise/docs/release-notes), [Gemini Notebook Enterprise, Gemini Enterprise, or both?](https://docs.cloud.google.com/gemini/enterprise/docs/choose-product)).
- To enable partner models in Model Garden, a person needs the Consumer Procurement Entitlement Manager role. The organization policy must allow the Cloud Commerce Consumer Procurement API ([Partner models for MaaS](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/partner-models/use-partner-models)).
- Google does not share customer prompts and model responses with third parties, including partner model providers ([Partner models for MaaS](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/partner-models/use-partner-models)).

## Pre-trained API or a Gemini prompt

Google publishes no single guide for this choice. The facts below come from the product docs.

| Factor | Pre-trained API | Gemini prompt |
|---|---|---|
| Scope | Prebuilt features, such as image labels, face detection, OCR, and SafeSearch, billed per use | One multitask model that you can tune or customize for a task |
| Output | Fixed fields, such as a label with a confidence score and a topicality rating | Your own structure. With a response schema, the output always follows it. |
| Long or live audio | Asynchronous transcription of up to 480 minutes, and streaming over gRPC | The Agent Platform speech feature accepts 60 seconds or 10 MB at most |
| Data location | Speech-to-Text V2 runs in regions such as Belgium. Translation Advanced has regional endpoints. | The global endpoint gives no data residency. US and EU multi-region endpoints keep processing in that area. |
| Lifecycle | Some task APIs now send users to Gemini: Video Intelligence and Imagen | Google retires model versions on published dates. Stable models stay for at least 12 months. |

Sources: [AI APIs](https://cloud.google.com/ai/apis), [Vision AI](https://cloud.google.com/vision), [Vision features list](https://docs.cloud.google.com/vision/docs/features-list), [Structured output](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/control-generated-output), [Speech-to-Text request types](https://docs.cloud.google.com/speech-to-text/docs/v1/speech-to-text-requests), [Convert speech to text](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/speech/speech-to-text), [Migrate to Speech-to-Text V2](https://docs.cloud.google.com/speech-to-text/docs/migration), [Overview of the Cloud Translation API](https://docs.cloud.google.com/translate/docs/api-overview), [Data residency](https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/data-residency), [Video Intelligence API documentation](https://docs.cloud.google.com/video-intelligence/docs), [Release notes](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/release-notes), [Model versions and lifecycle](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/model-versions).

Use these rules:

- **Use a pre-trained API** when one feature matches the task exactly. It also fits long or live audio and regional processing.
- **Use a Gemini prompt** when the task mixes text and images, needs reasoning, or needs your own labels or schema. Gemini also replaces the deprecated video and image APIs.
- **Use Document AI** when you build a document pipeline. It handles forms, known document types, and your own document types.

## Search and conversation

**Agent Search.** A search app connects to one or more data stores. It gives AI answers grounded in your data, with citations. It searches documents in Cloud Storage or BigQuery, structured data, and public websites ([Introduction to custom search](https://docs.cloud.google.com/generative-ai-app-builder/docs/about-generic-search)). Agent Search works as an out-of-the-box search engine for RAG ([APIs for search and RAG](https://docs.cloud.google.com/generative-ai-app-builder/docs/builder-apis)). For the choice between Agent Search, RAG Engine, and Vector Search, see [Choosing AI and ML solutions](note:1.3-ai-solutions).

| Need | Product |
|---|---|
| Search over data from any industry, on public websites or in structured or unstructured data | Agent Search custom search |
| Search over healthcare records in FHIR data stores | Agent Search for healthcare |
| Search over movies, videos, and music | Agent Search for media |
| Product search and recommendations for a retailer | AI Commerce Search in GECX |

Sources: [Introduction to custom search](https://docs.cloud.google.com/generative-ai-app-builder/docs/about-generic-search), [Agent Search documentation](https://docs.cloud.google.com/generative-ai-app-builder/docs), [Agent Search product page](https://cloud.google.com/products/gemini-enterprise-agent-platform/agent-search).

**Conversation.** CX Agent Studio is a minimal-code builder for conversational agents, built on the Agent Development Kit (ADK) ([CX Agent Studio](https://docs.cloud.google.com/gemini-enterprise-cx/cx-agent-studio)). GECX brings shopping and customer service together ([Gemini Enterprise for CX](https://docs.cloud.google.com/gemini-enterprise-cx)). Agent designs are generative, deterministic, or both:

| Design | Use it when | Trade-off |
|---|---|---|
| Playbooks (generative) | You describe the task in natural language and let the LLM drive | Less design time, less control |
| Flows (deterministic) | Responses need explicit control | More design time |
| Generative fallback | A flow needs an answer when user input matches no intent | Adds LLM responses only for unmatched input |

Sources: [Generative versus deterministic](https://docs.cloud.google.com/dialogflow/cx/docs/generative-deterministic).

For voice transcription in Agent Assist, Google recommends the Chirp 3 model, subject to regional availability ([Voice transcription](https://docs.cloud.google.com/gemini-enterprise-cx/agent-assist/transcription)).

## Vision and documents

| Need | Use |
|---|---|
| Labels, faces, landmarks, or explicit-content ratings for images | Vision API. Face detection does not identify people. |
| Fast text extraction from images at high volume | Vision API text detection |
| Dense text or handwriting in an image of a document | Vision API document text detection |
| Scanned documents and PDFs in a processing pipeline | Document AI Enterprise Document OCR |
| Tables and key-value pairs from forms | Document AI Form Parser |
| Chunks for a RAG index | Document AI Layout Parser |
| Fields from known document types, such as invoices or IDs | Document AI pretrained processors |
| Fields from your own document types | Document AI Custom Extractor. The default model needs no training. |
| Custom object detection | AutoML image object detection |
| Ingest and analyze video streams | Agent Platform Vision |

Sources: [Vision features list](https://docs.cloud.google.com/vision/docs/features-list), [OCR with Google AI](https://cloud.google.com/use-cases/ocr), [Document AI overview](https://docs.cloud.google.com/document-ai/docs/overview), [Custom extractor mechanisms](https://docs.cloud.google.com/document-ai/docs/ce-mechanisms), [Train and use your own models](https://docs.cloud.google.com/gemini-enterprise-agent-platform/machine-learning/training-overview), [Agent Platform Vision overview](https://docs.cloud.google.com/vision-ai/docs/overview).

Product Search is in maintenance mode, and Google points to Vision Warehouse ([Vision API Product Search](https://docs.cloud.google.com/vision/product-search/docs)). The Gemini-based v1.6 versions (Preview) of some Document AI processors use the global endpoint. They are not compliant with data residency ([Processor list](https://docs.cloud.google.com/document-ai/docs/processors-list)).

## Image, video, and audio

**Image.** Gemini generates images from text and edits images over several turns ([Generate images with Gemini](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/image-generation), [Edit images with Gemini](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-edit-images)). Nano Banana 2 gives a mainstream price and low latency. Nano Banana Pro fits accurate text rendering and grounding with Google Search ([Generative media models](https://cloud.google.com/ai/generative-media)). Google adds signed C2PA Content Credentials to media from supported Google models ([Content Credentials](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/content-credentials)).

**Video.** Veo 3.1 targets the highest visual fidelity. Veo 3.1 Fast targets standard production. Veo 3.1 Lite (Preview) is the most cost-effective model for high volume ([Generative media models](https://cloud.google.com/ai/generative-media)). To analyze video content, add the video to a Gemini request ([Video understanding](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/video-understanding)).

**Audio.**

| Need | Use |
|---|---|
| Audio of 1 minute or less | Speech-to-Text synchronous recognition |
| Long files in Cloud Storage, up to 480 minutes | Speech-to-Text batch (asynchronous) recognition |
| Live audio | Speech-to-Text streaming recognition (gRPC only) |
| Phone call audio at 8 kHz | Speech-to-Text telephony model, or Chirp 3 |
| A real-time voice conversation with a model | Gemini Live API |
| Speech with style control from text prompts | Gemini-TTS |
| Music clips and tracks | Lyria. Lyria 3 Clip (Preview) makes clips. Lyria 3 Pro (Preview) makes full tracks. |

Sources: [Speech-to-Text request types](https://docs.cloud.google.com/speech-to-text/docs/v1/speech-to-text-requests), [Compare transcription models](https://docs.cloud.google.com/speech-to-text/docs/transcription-model), [Voice transcription](https://docs.cloud.google.com/gemini-enterprise-cx/agent-assist/transcription), [Gemini Live API overview](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/live-api), [Gemini-TTS](https://docs.cloud.google.com/text-to-speech/docs/gemini-tts), [Lyria](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/music/overview), [Google models](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/google-models).

## Gemini Enterprise

Gemini Enterprise is for employees. Agent Platform is for developers who build applications ([Google AI Studio vs. Agent Platform vs. Gemini Enterprise app](https://cloud.google.com/ai/gemini)).

| Edition | Key facts |
|---|---|
| Business | 1 to 500 seats. No full-code agents and fewer connectors. |
| Standard and Plus | Custom agents and third-party agents. Both include Gemini Notebook Enterprise. |
| Pay-as-you-go | One seat to start. Needs an invoiced Cloud Billing account. |
| Frontline | Needs 150 or more Standard or Plus users. Users get only the organization agents that an administrator provisions. The docs conflict on Made by Google agents, so see the cited pages. |

Sources: [Compare editions of Gemini Enterprise](https://docs.cloud.google.com/gemini/enterprise/docs/editions), [Gemini Enterprise app](https://cloud.google.com/gemini-enterprise), [Browse agents with Agent Gallery](https://docs.cloud.google.com/gemini/enterprise/docs/agent-gallery), [Gemini Notebook Enterprise, Gemini Enterprise, or both?](https://docs.cloud.google.com/gemini/enterprise/docs/choose-product).

**Agents.** Users find prebuilt agents in the Agent Gallery, such as Deep Research and Gemini Notebook Enterprise. They build custom agents in Workflow Builder, a no-code and low-code tool ([Gemini Enterprise concepts](https://docs.cloud.google.com/gemini/enterprise/docs/concepts), [Browse agents with Agent Gallery](https://docs.cloud.google.com/gemini/enterprise/docs/agent-gallery), [Workflow Builder overview](https://docs.cloud.google.com/gemini/enterprise/docs/workflow-builder)). Developers build agents with ADK and host them on Agent Runtime (formerly Vertex AI Agent Engine). Administrators then register those agents in Gemini Enterprise ([Register ADK agents](https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-adk-agent)). Agents built with A2A on any platform can also connect, in Preview ([Register A2A agents](https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-a2a-agent)). Developers add Model Armor in the agent code ([Register ADK agents](https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-adk-agent)). See [Securing AI workloads](note:3.1-securing-ai).

**Connectors.** A connector creates a data store ([Connect a third-party data source](https://docs.cloud.google.com/gemini/enterprise/docs/connectors/connect-third-party-data-source)). Prebuilt connectors include Confluence, Jira, SharePoint, and ServiceNow ([What is Gemini Enterprise?](https://docs.cloud.google.com/gemini/enterprise/docs)). Choose how data reaches the index:

| Mode | Use it when | Trade-off |
|---|---|---|
| Ingestion (indexing) | Search quality matters most | Uses more storage and time |
| Federation | You do not want to copy data | Search quality might be lower. The query goes to the source systems. |

Sources: [Introduction to connectors and data stores](https://docs.cloud.google.com/gemini/enterprise/docs/connectors/introduction-to-connectors-and-data-stores), [Connect a third-party data source](https://docs.cloud.google.com/gemini/enterprise/docs/connectors/connect-third-party-data-source).

Search results show only documents that the user can already open in the source ([Configure access controls](https://docs.cloud.google.com/gemini/enterprise/docs/identity)). For third-party connectors, Google recommends Workforce Identity Federation ([Gemini Enterprise security overview](https://docs.cloud.google.com/gemini/enterprise/docs/security-overview)).

**Location.** Google recommends the global location unless security or regulations require the US or EU multi-region ([Data residency for Gemini Enterprise](https://docs.cloud.google.com/gemini/enterprise/docs/locations)). CMEK needs a US or EU multi-region app or data store, not a global one ([Customer-managed encryption keys](https://docs.cloud.google.com/gemini/enterprise/docs/cmek)).

## Gemini Notebook Enterprise

Gemini Notebook Enterprise (formerly NotebookLM Enterprise) is a highly compliant, enterprise-ready version of Gemini Notebook ([What is Gemini Notebook Enterprise?](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview)). The rename kept the features and the API endpoints ([Gemini Enterprise release notes](https://docs.cloud.google.com/gemini/enterprise/docs/release-notes)).

| | Gemini Notebook Enterprise | Gemini Enterprise |
|---|---|---|
| Use it when | You build a reference point for a topic from known, trusted sources | The place to start a search across company data is unknown |
| Data | Sources stay in your project, in the US or EU multi-region | Connectors to many company systems |
| Sharing | IAM roles only. Notebooks cannot be shared publicly. | Results follow source permissions |

Sources: [Gemini Notebook Enterprise, Gemini Enterprise, or both?](https://docs.cloud.google.com/gemini/enterprise/docs/choose-product), [What is Gemini Notebook Enterprise?](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview), [Configure access controls](https://docs.cloud.google.com/gemini/enterprise/docs/identity).

The IAM roles still use the old name, for example Cloud NotebookLM User ([What is Gemini Notebook Enterprise?](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview)). Projects with VPC Service Controls cannot add website URLs as notebook sources ([Gemini Enterprise release notes](https://docs.cloud.google.com/gemini/enterprise/docs/release-notes)).

## Model Garden integration

Model Garden has Google, partner, and open models. An organization policy controls which models people can use ([Overview of Model Garden](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/model-garden/explore-models)). [Choosing AI and ML solutions](note:1.3-ai-solutions) compares Model as a Service (MaaS) with self-deployment. This section covers setup.

| Step | What to know |
|---|---|
| Enable a partner model | Consumer Procurement Entitlement Manager role. The organization policy must allow the Cloud Commerce Consumer Procurement API. |
| Pick the endpoint | Use regional endpoints for data residency. Partner models do not support Provisioned Throughput on the global endpoint. |
| Block the global endpoint | The `constraints/gcp.restrictEndpointUsage` constraint blocks requests to the global endpoint |
| Pay for a self-deployed partner model | You pay for model usage and for the infrastructure. Reservations and CUDs apply. |
| Deploy a Hugging Face model | Agent Platform for managed MLOps. GKE for existing Kubernetes skills and fine control. |
| Serve custom logic | A custom container, when pre-processing or post-processing is not in prebuilt containers |

Sources: [Partner models for MaaS](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/partner-models/use-partner-models), [Overview of self-deployed models](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/model-garden/self-deployed-models), [Use Hugging Face models](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/open-models/use-hugging-face-models), [Open models overview](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/open-models/choose-serving-option).

**Tuning.** Google recommends that you start with prompting and tune only if necessary ([Introduction to tuning](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tuning)).

- Supervised fine-tuning teaches a new skill, such as classification or entity extraction ([Introduction to tuning](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tuning)).
- Preference tuning uses human feedback data ([Introduction to tuning](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tuning)).
- For open models, distillation tunes a small student model from the outputs of a large teacher model ([Tuning for open models](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tuning/open-model-tuning)).
- QLoRA uses about 75% less peak GPU memory than LoRA. LoRA costs up to 40% less than QLoRA ([LoRA and QLoRA recommendations](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/model-garden/lora-qlora)).

## Exam traps

- **Video Intelligence API or Imagen for a new design.** Both are deprecated. Google recommends Gemini models ([Video Intelligence API documentation](https://docs.cloud.google.com/video-intelligence/docs), [Release notes](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/release-notes)).
- **Vision OCR for a scanned-document pipeline.** Google recommends Document AI for scanned documents and forms ([Vision features list](https://docs.cloud.google.com/vision/docs/features-list)).
- **Synchronous recognition for a long recording.** Synchronous requests accept 1 minute of audio or less ([Speech-to-Text request types](https://docs.cloud.google.com/speech-to-text/docs/v1/speech-to-text-requests)).
- **Chirp 3 on the V1 API.** Chirp 3 transcription is only in V2 ([Chirp 3 Transcription](https://docs.cloud.google.com/speech-to-text/docs/models/chirp-3)).
- **API keys with Translation - Advanced.** Advanced does not support API keys ([Overview of the Cloud Translation API](https://docs.cloud.google.com/translate/docs/api-overview)).
- **CMEK with a global Gemini Enterprise app.** CMEK needs the US or EU multi-region ([Customer-managed encryption keys](https://docs.cloud.google.com/gemini/enterprise/docs/cmek)).
- **Gemini Enterprise as the developer platform.** Developers build on Agent Platform. Employees use the Gemini Enterprise app ([Google AI Studio vs. Agent Platform vs. Gemini Enterprise app](https://cloud.google.com/ai/gemini)).
- **Public sharing of a notebook.** Gemini Notebook Enterprise notebooks cannot be shared publicly ([What is Gemini Notebook Enterprise?](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview)).
- **Tuning before prompting.** Google says to start with prompting ([Introduction to tuning](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tuning)).
- **The global endpoint for data residency.** Requests to the global endpoint can run in any location ([Data residency](https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/data-residency)).
