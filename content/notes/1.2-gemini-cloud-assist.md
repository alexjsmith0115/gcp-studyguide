## Why it matters

Gemini Cloud Assist is the AI assistant for design, operations, troubleshooting, and cost work in Google Cloud. The exam guide lists it under objective 1.2 (technical requirements) and objective 5.1 (advice to development and operations teams). An architect decides where the assistant helps, which data it can see, who can use it, and which projects must not turn it on. Expect scenarios that combine a use case with a constraint: data residency, least privilege, support level, or organization scope.

## Key points

- Gemini Cloud Assist is a Preview offering under the Pre-GA Offering Terms. It helps with design and build, support and troubleshooting, and optimization ([Gemini Cloud Assist overview](https://docs.cloud.google.com/cloud-assist/overview)).
- Gemini does not use your prompts or its responses as data to train its models ([How Gemini products use your data](https://docs.cloud.google.com/gemini/docs/discover/data-governance)).
- Gemini Cloud Assist can store data in any Google Cloud data center. Do not enable its API for projects that have data residency or customer-managed encryption key (CMEK) requirements ([Set up Gemini Cloud Assist](https://docs.cloud.google.com/cloud-assist/set-up-gemini)).
- Gemini Cloud Assist has the same permissions as the user who asks it. The recommended roles are Gemini Cloud Assist User and Cloud Asset Viewer ([IAM requirements](https://docs.cloud.google.com/cloud-assist/iam-requirements)).
- You set it up for a project or for a folder. It needs `geminicloudassist.googleapis.com` and `cloudaicompanion.googleapis.com`; enabling the first also enables the second ([Set up Gemini Cloud Assist](https://docs.cloud.google.com/cloud-assist/set-up-gemini)).
- Investigations are a root-cause analysis (RCA) tool. Since April 10, 2026, only users with a Premium Support contract, or with access from their account team, can create or run them ([Investigations](https://docs.cloud.google.com/cloud-assist/investigations)).
- One investigation covers one project or one App Hub application. Its OAuth token has only the access of the user or service account that runs it, and it never changes data ([Investigations](https://docs.cloud.google.com/cloud-assist/investigations)).
- With Application Design Center, Gemini Cloud Assist turns requirements into Terraform. You deploy it from the console or through your own pipeline ([Design an application with Gemini](https://docs.cloud.google.com/cloud-assist/design-application)).
- Gemini output can look correct and still be wrong. Validate all output before you use it ([Gemini Cloud Assist overview](https://docs.cloud.google.com/cloud-assist/overview)).

## What it does across the application lifecycle

Gemini Cloud Assist is a set of agents in the Cloud Assist panel, in product pages, and in hubs such as Cloud Hub and FinOps hub. It uses your project ID and organization ID, the visible text of the current console page, and session memory as context ([Gemini Cloud Assist overview](https://docs.cloud.google.com/cloud-assist/overview)).

| Stage | What it does | Limit or note |
|---|---|---|
| Design | Turns requirements into an architecture diagram and an Application Design Center template | Does not support applications in a host project or a single-project boundary |
| Build | Generates gcloud commands, `kubectl` manifests, and Terraform; tests generated organization policies in chat; suggests IAM roles | The IAM role picker suggests predefined roles only |
| Deploy | Deploys the template from the console, or gives you Terraform for your pipeline | Application Design Center is GA; Gemini Cloud Assist is Preview |
| Operate | Answers questions about resources, IAM grants, recent changes, metrics, and incidents; summarizes a log entry | Answers include an equivalent query that you can run to check them |
| Troubleshoot | Runs investigations over logs, metrics, and configurations; proposes root causes; moves results into a support case | Premium Support contract or account-team access |
| Optimize | Explains cost changes, shows waste, drafts reports for engineering teams | Cost totals are before committed use discounts (CUDs) and credits |

Sources: [Gemini Cloud Assist overview](https://docs.cloud.google.com/cloud-assist/overview), [Use Gemini Cloud Assist in the console](https://docs.cloud.google.com/cloud-assist/chat-panel), [Design an application with Gemini](https://docs.cloud.google.com/cloud-assist/design-application), [IAM role picker](https://docs.cloud.google.com/iam/docs/role-picker-gemini), [View and analyze log entries](https://docs.cloud.google.com/logging/docs/view/logs-explorer-interface), [Investigations](https://docs.cloud.google.com/cloud-assist/investigations), [Application Design Center now GA](https://cloud.google.com/blog/products/application-development/application-design-center-now-ga).

## How an architect uses it

Treat Gemini Cloud Assist as a fast first draft and a fast search tool. The decision is which tasks it may do, in which projects, and with which review step.

| Use it when… | Do not use it, or use something else, when… |
|---|---|
| You need a first design from requirements. Refine it in the Application Design Center canvas. | The project has data residency or CMEK requirements. Keep the API disabled there. |
| A team must list resources, IAM grants, or recent changes quickly. Run the query that the answer gives to check it. | You need prices. The chat generally does not give service pricing data. |
| An incident spans logs, metrics, and configuration in one project or one App Hub application, and you have Premium Support. | The incident spans several projects that are not in one App Hub application. |
| A FinOps team needs a short summary of cost drivers and waste. | You need chargeback numbers after discounts. Use the Cloud Billing tools ([Cost optimization](note:4.2-cost-optimization)). |
| Every answer must follow a standard, such as "always use CMEK". Set custom instructions for the project. | You plan to apply generated code or policies without review. |

Sources: [Set up Gemini Cloud Assist](https://docs.cloud.google.com/cloud-assist/set-up-gemini), [Use Gemini Cloud Assist in the console](https://docs.cloud.google.com/cloud-assist/chat-panel), [Investigations](https://docs.cloud.google.com/cloud-assist/investigations), [Custom instructions](https://docs.cloud.google.com/cloud-assist/custom-instructions).

For objective 5.1, give developers and operators Gemini Cloud Assist for drafts, inventory, and triage. Keep your pipeline and review gates as the control points ([Advising teams: deployment and APIs](note:5.1-deployment-and-apis)).

## Design with Application Design Center

Application Design Center lets platform teams build organizational standards into templates, so each deployment follows security and compliance rules from the start ([Application Design Center overview](https://docs.cloud.google.com/application-design-center/docs/overview)). Gemini Cloud Assist is its natural-language front end. The flow ([Design an application with Gemini](https://docs.cloud.google.com/cloud-assist/design-application)):

1. In the Cloud Assist panel, write a product-oriented prompt ("Cloud Run, Cloud SQL, and a load balancer") or an outcome-oriented prompt ("a pipeline for async events").
2. Review the proposed architecture and the purpose of each component.
3. Click **Edit App Design** to create an application template on the canvas.
4. Refine with more prompts or with manual edits. Gemini keeps the context of your manual changes.
5. Deploy from the console, which tracks template revisions. Or download the Terraform for your own tools.

Facts that decide exam scenarios:

- Platform teams publish approved templates to a catalog. Components are Google components or your own imported Terraform modules. A design can be assessed against Security Command Center policies (Preview) ([Application Design Center overview](https://docs.cloud.google.com/application-design-center/docs/overview)).
- A user without Application Design Center access sees the design in preview mode. **Get Code** downloads the Terraform ([Design an application with Gemini](https://docs.cloud.google.com/cloud-assist/design-application)).
- The single-project boundary (Preview) needs no organization, but Gemini Cloud Assist does not support applications in it. The folder-level boundary needs an organization resource ([Set up Application Design Center](https://docs.cloud.google.com/application-design-center/docs/setup)).
- Application Design Center charges for its artifact bucket, for Cloud Build during deployment, and for deployed resources ([Application Design Center pricing](https://cloud.google.com/products/application-design-center/pricing)).

## Troubleshoot with investigations

An investigation collects ranked **observations** from logs, configurations, and metrics, with links to the source data. It proposes probable root causes, gives several hypotheses when it is not sure, and recommends next steps.

| Topic | What the docs say |
|---|---|
| Access | Premium Support contract or account-team access, since April 10, 2026 |
| Entry points | Investigations page; Logs Explorer entries with severity Warning or higher; alerts with a resource label; chat; Cloud Hub |
| Scope | One project, or one App Hub application in a folder configured for application management |
| Storage | Project-level results stay in the project. Application-level results go to the App Hub management project. |
| Permissions | The token has the access of the user or service account that runs it and never changes data. The creator gets Investigation Owner on that investigation. |
| Accuracy | Runs are not deterministic. An accurate start time improves correlation. |
| Escalation | With a support package, **Request support** moves the details into a support case |

Sources: [Investigations](https://docs.cloud.google.com/cloud-assist/investigations), [Create an investigation](https://docs.cloud.google.com/cloud-assist/create-investigation).

Two related features:

- **Proactive mode** (Private Preview, Premium Support) investigates alerts and cost anomalies in the background and delivers results through Eventarc ([Release notes](https://docs.cloud.google.com/cloud-assist/release-notes)). It runs as a dedicated agent identity that reads only what you grant to it ([Set up Proactive Mode](https://docs.cloud.google.com/cloud-assist/proactive-agents-setup)).
- **Investigate log** in Logs Explorer summarizes one log entry, based only on the text of that entry. For an audit log, it shows who did what and whether it was allowed ([View and analyze log entries](https://docs.cloud.google.com/logging/docs/view/logs-explorer-interface)).

For RCA practice, see [Testing and troubleshooting](note:4.1-testing-and-troubleshooting) and [Google Cloud Observability](note:6.2-observability).

## Optimize cost

- The Cloud Hub **Optimization** page shows Gemini insights about cost changes. The data comes from the App Optimize API, which has no additional charge ([Optimize costs with Gemini](https://docs.cloud.google.com/hub/docs/optimize-gemini), [Set up Cloud Hub](https://docs.cloud.google.com/hub/docs/setup-cloud-hub)).
- Cost analysis in chat needs the App Optimize API and the Cloud Hub Operator role. Totals use contract prices before CUDs or other credits. An application total excludes shared resources ([Use Gemini Cloud Assist in the console](https://docs.cloud.google.com/cloud-assist/chat-panel)).
- In Cloud Billing, Gemini builds cost reports from prompts. In FinOps hub, it summarizes top waste and drafts an email report for engineering teams ([Gemini Cloud Assist in Cloud Billing](https://docs.cloud.google.com/billing/docs/how-to/gemini/overview)).

Budgets, commitments, and billing export are in [Cost optimization](note:4.2-cost-optimization).

## Data governance, privacy, and security

| Topic | What the docs say | Design consequence |
|---|---|---|
| Model training | Prompts and responses are not used to train Gemini models | Training is not a reason to block the tool |
| Prompt and response sharing | Off by default. If an admin turns it on, Google processes the project's prompts and responses for product improvement, keeps anonymized copies for at most two years, and never trains models on them. | Decide per project |
| Data location | Chat conversations and investigations can be stored in any Google Cloud data center | Keep regulated data out of prompts and out of residency or CMEK projects |
| Security features | VPC Service Controls: supported. CMEK, data residency at rest, Access Transparency: not supported. | A perimeter does not fix residency or CMEK needs |
| Perimeters | Gemini Cloud Assist reaches only data and APIs inside the perimeter. Investigations are supported inside a perimeter. Google stopped this support for a period from April 13, 2026. | Add `cloudaicompanion.googleapis.com` to the perimeter too |
| Grounding | Default Grounding with Google Search does not support data residency, Access Transparency, or CMEK offerings. Web Grounding for Enterprise suits regulated industries. | Choose Web Grounding for Enterprise for regulated projects |
| Page context | Sharing of the visible page text is on by default. Each user can turn it off. | Tell users what goes into a prompt |
| Chat history | Deleted after 180 days. Principals with `cloudaicompanion.topics.get` (for example, Owner) can read other users' history through the API. | Limit the Owner role |

Sources: [Prompt and response sharing](https://docs.cloud.google.com/cloud-assist/configure-prompt-response-sharing), [Configure administrator settings](https://docs.cloud.google.com/cloud-assist/admin-settings), [Investigations](https://docs.cloud.google.com/cloud-assist/investigations), [Certifications and security for Gemini](https://docs.cloud.google.com/gemini/docs/discover/certifications), [VPC Service Controls supported products](https://docs.cloud.google.com/vpc-service-controls/docs/supported-products), [Feature deprecations](https://docs.cloud.google.com/cloud-assist/deprecations/features), [Configure grounding](https://docs.cloud.google.com/cloud-assist/configure-grounding), [Use Gemini Cloud Assist in the console](https://docs.cloud.google.com/cloud-assist/chat-panel).

Gemini products in Google Cloud hold certifications such as SOC 2, HIPAA, and ISO 27001 ([Certifications and security for Gemini](https://docs.cloud.google.com/gemini/docs/discover/certifications)). A certification does not remove the data-location limits. See [Designing for compliance](note:3.2-compliance).

## IAM roles

A user who cannot read a resource cannot ask Gemini about it either. Some tasks also need product roles, for example Cloud Hub Operator for cost analysis ([IAM requirements](https://docs.cloud.google.com/cloud-assist/iam-requirements)).

| Role | What it allows | Give it to |
|---|---|---|
| Gemini Cloud Assist Viewer | View investigations, reports, and agent configurations; no chat | Reviewers |
| Gemini Cloud Assist User | Invoke agents, chat, create and share own artifacts | Most users (recommended) |
| Gemini Cloud Assist Editor | User, plus delete chat topics and artifacts, update some agent configurations | Team leads |
| Gemini Cloud Assist Admin | Editor, plus enable proactive agents and data sharing, share artifacts project-wide | A small admin group |
| Cloud Asset Viewer | Lets the agent discover the topology of resources and policies | Every user, with the User role |
| Gemini for Google Cloud Settings Admin | Configure grounding and custom instructions | The admin group |

Sources: [IAM requirements](https://docs.cloud.google.com/cloud-assist/iam-requirements), [Configure grounding](https://docs.cloud.google.com/cloud-assist/configure-grounding), [Custom instructions](https://docs.cloud.google.com/cloud-assist/custom-instructions).

In April 2026, `geminicloudassist.agents.invoke` replaced `cloudaicompanion.instances.completeTask`. Update custom roles that used the old permission ([Release notes](https://docs.cloud.google.com/cloud-assist/release-notes)). See also [IAM and resource hierarchy](note:3.1-iam-and-hierarchy).

## Setup, settings, and status

Project setup ([Set up Gemini Cloud Assist](https://docs.cloud.google.com/cloud-assist/set-up-gemini)):

1. Enable `geminicloudassist.googleapis.com`.
2. Enable `cloudasset.googleapis.com`, `designcenter.googleapis.com`, `appoptimize.googleapis.com`, and `apphub.googleapis.com`. Inside a VPC Service Controls perimeter, use gcloud and leave out `appoptimize.googleapis.com`.
3. Grant `roles/geminicloudassist.user` and `roles/cloudasset.viewer`.

Folder setup is console-only. It enables the APIs for the projects in the folder now; projects that you add later do not get Gemini Cloud Assist automatically. For applications, you also enable application management, which creates a management project with a billing account ([Set up Gemini Cloud Assist](https://docs.cloud.google.com/cloud-assist/set-up-gemini)).

Admin setting defaults: Grounding with Google Search; page context sharing enabled; prompt and response sharing disabled; proactive agents disabled; no custom instructions ([Configure administrator settings](https://docs.cloud.google.com/cloud-assist/admin-settings)). Custom instructions hold up to 3,000 characters and apply to all users in the project ([Custom instructions](https://docs.cloud.google.com/cloud-assist/custom-instructions)).

Status and price: the chat panel has no cost while it is in Preview ([Use Gemini Cloud Assist in the console](https://docs.cloud.google.com/cloud-assist/chat-panel)). Gemini Code Assist Enterprise includes additional Gemini Cloud Assist features, at no additional charge during the preview period ([Gemini for Google Cloud pricing](https://cloud.google.com/products/gemini/pricing)).

## Exam traps

- **"Put the regulated project in a VPC Service Controls perimeter, then enable Gemini Cloud Assist."** A perimeter does not give data residency or CMEK, and Gemini Cloud Assist supports neither ([Certifications and security for Gemini](https://docs.cloud.google.com/gemini/docs/discover/certifications)).
- **"Gemini trains on our prompts, so block it."** It does not. Optional sharing is off by default and serves product improvement only ([Prompt and response sharing](https://docs.cloud.google.com/cloud-assist/configure-prompt-response-sharing), [Configure administrator settings](https://docs.cloud.google.com/cloud-assist/admin-settings)).
- **"Grant Gemini Cloud Assist Admin so that developers can chat."** The User role allows chat. Admin also controls data sharing and proactive agents ([IAM requirements](https://docs.cloud.google.com/cloud-assist/iam-requirements)).
- **"Gemini shows developers resources that they cannot read."** It has the same permissions as the user ([IAM requirements](https://docs.cloud.google.com/cloud-assist/iam-requirements)).
- **"Run one investigation across three unrelated projects."** Group the resources into one App Hub application in an app-enabled folder ([Investigations](https://docs.cloud.google.com/cloud-assist/investigations)).
- **"Use a single-project boundary for application investigations."** Gemini Cloud Assist does not support applications in a host project or a single-project boundary ([Create an investigation](https://docs.cloud.google.com/cloud-assist/create-investigation)).
- **"Use the Gemini cost totals for chargeback."** They are before CUDs and credits and exclude shared resources ([Use Gemini Cloud Assist in the console](https://docs.cloud.google.com/cloud-assist/chat-panel)).
- **"Enable it on the folder once; new projects get it."** Projects added later do not ([Set up Gemini Cloud Assist](https://docs.cloud.google.com/cloud-assist/set-up-gemini)).
