# Other product name changes (data, storage, and productivity)

Google renamed these products recently. Older exam questions, blog posts, and training material use the previous names, so learn both. The notes use the new name and put the previous name in parentheses at the first mention. For the Vertex AI renames, see the AI product name changes page.

Checked on 2026-09-24. Updated on 2026-09-25.

| Previous name | New name | Source |
|---|---|---|
| Dataproc (Dataproc on Compute Engine) and Google Cloud Serverless for Apache Spark (earlier Dataproc Serverless for Spark) | Managed Service for Apache Spark (cluster deployment and serverless deployment) | [Compare Managed Service for Apache Spark serverless and cluster deployments](https://docs.cloud.google.com/managed-spark/docs/concepts/serverless-spark-compare), [Managed Service for Apache Spark release notes](https://docs.cloud.google.com/managed-spark/docs/release-notes) (September 5, 2025 still says "Dataproc Serverless for Spark") |
| Cloud Composer | Managed Service for Apache Airflow (Managed Airflow). The `gcloud composer` commands and the API names did not change. | [Managed Service for Apache Airflow versioning overview](https://docs.cloud.google.com/composer/docs/composer-versioning-overview) |
| Dataplex Universal Catalog (Dataplex Catalog) | Knowledge Catalog. Data Catalog began a phased shutdown on June 1, 2026. | [Knowledge Catalog release notes](https://docs.cloud.google.com/knowledge-catalog/docs/release-notes) |
| BigLake | Lakehouse | [Lakehouse release notes](https://docs.cloud.google.com/lakehouse/docs/release-notes) |
| Analytics Hub | BigQuery sharing | [Introduction to BigQuery sharing](https://docs.cloud.google.com/bigquery/docs/analytics-hub-introduction) |
| Anywhere Cache (Cloud Storage) | Rapid Cache | [Rapid Cache](https://docs.cloud.google.com/storage/docs/rapid/rapid-cache) |
| NotebookLM Enterprise | Gemini Notebook Enterprise. IAM role names still say NotebookLM. | [What is Gemini Notebook Enterprise?](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview) |
| Google Cloud Skills Boost | Google Skills | [Google Cloud training](https://cloud.google.com/learn/training) |
| Cloud Functions (2nd gen) and Cloud Functions (1st gen) | Cloud Run functions and Cloud Run functions (1st gen). Functions now deploy through the Cloud Run Admin API. | [Compare Cloud Run functions](https://docs.cloud.google.com/run/docs/functions/comparison) |
| Cloud Firewall Plus | Cloud NGFW Enterprise | [Announcing Next Gen Firewall Enterprise, now in GA](https://cloud.google.com/blog/products/identity-security/announcing-next-gen-firewall-enterprise-now-in-ga-next24) |
| Migrate for Compute Engine (version 4.x) | Migrate to Virtual Machines (version 5). Version 4.x reached end of life on April 30, 2024. The CLI changed from `m4c` to `m2vm`. | [Migrate to Virtual Machines release notes](https://docs.cloud.google.com/migrate/virtual-machines/docs/5.0/resources/release-notes) |
| Migrate for Anthos and GKE | Migrate to Containers. The release notes still use the old name for the 2022 release of the v1 API. | [Migrate to Containers release notes](https://docs.cloud.google.com/migrate/containers/docs/release-notes) |
| BeyondCorp Enterprise | Chrome Enterprise Premium. The old docs URL redirects to the new product. | [Chrome Enterprise Premium overview](https://docs.cloud.google.com/chrome-enterprise-premium/docs/overview) |
| Cloud operations suite (Stackdriver) | Google Cloud Observability. The docs still use the `/stackdriver/` path. | [Observability in Google Cloud](https://docs.cloud.google.com/stackdriver/docs) |
| Log Analytics (Cloud Logging) | Observability Analytics. It runs SQL on upgraded log buckets and can also query trace data. The docs page keeps its old URL, and the Logging release notes used "Log Analytics" until March 12, 2026. | [Analyze logs using Logs Explorer and Observability Analytics](https://docs.cloud.google.com/logging/docs/log-analytics), [Logging release notes](https://docs.cloud.google.com/logging/docs/release-notes) |
